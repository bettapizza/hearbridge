# Android Prototype

This module contains a small Jetpack Compose interface for validating the core caption experience.

It currently:

- Displays a large caption surface
- Simulates starting and stopping captions
- Simulates holding text on screen
- Clearly labels itself as a prototype
- Does not capture audio
- Does not connect to hearing aids

Before production work, update dependencies to currently supported versions, add a generated Gradle wrapper, add tests, and establish CI.
