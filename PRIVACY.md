# Privacy Principles

HearBridge is intended to be private by default.

## Baseline commitments

- No account is required for core captioning.
- No advertising SDKs.
- No analytics by default.
- Microphone access starts only after an explicit user action.
- Raw audio is not retained after processing.
- Transcripts are temporary unless the user explicitly saves them.
- Saved transcripts should use encrypted local storage.
- Users must be able to delete saved content completely.
- The app must clearly identify local versus remote processing.

## Conversation consent

Local laws and expectations concerning recording and transcription vary. HearBridge should provide a visible captioning indicator and an optional consent notice. Users are responsible for following applicable laws and organizational policies.

## Future cloud features

A cloud transcription provider may not be added silently. Any future cloud option must be optional, clearly labeled, documented, and disabled by default.
